# ClauseLens Issues

Public issue tracker for the **ClauseLens browser extension**.

The ClauseLens source code is maintained in a private repository. This repository is only for reporting bugs, requesting features, and tracking known problems.

## Get help

- [Support website](https://clauselens-support.vercel.app)
- [Report a bug](https://github.com/ArshilHapani/clauselens-issues/issues/new)
- [View existing issues](https://github.com/ArshilHapani/clauselens-issues/issues)
- [Email support](mailto:arshil.clauselens@gmail.com?subject=ClauseLens%20support)

## Before creating an issue

Please search the existing issues first to avoid duplicates.

When reporting a bug, include:

- Browser name and version
- ClauseLens extension version
- Page URL, when safe to share
- Steps to reproduce the problem
- What you expected to happen
- What actually happened
- Screenshots or error messages, if helpful

## Privacy

Do not include confidential agreements, personal information, authentication details, API keys, or private document text in a public issue.

ClauseLens analyzes supported documents locally in your browser. See the [privacy page](https://clauselens-support.vercel.app/privacy) for more information.

For questions containing private information, use [email support](mailto:arshil.clauselens@gmail.com?subject=ClauseLens%20support) instead.

## Feature requests

Feature requests are welcome. Please describe:

- The problem you want to solve
- How the feature should work
- Why it would be useful
- Any alternatives you currently use

## Security reports

Do not disclose security vulnerabilities publicly.

Please report security concerns privately by emailing [arshilhapani998@gmail.com](mailto:arshil.clauselens@gmail.com?subject=ClauseLens%20security).

## Source code

ClauseLens is not currently open source. This repository does not contain the extension’s source code and is not intended for pull requests.
